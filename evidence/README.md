# Evidence

Populate this directory after running the demo.

Recommended evidence:

- `discovery-artifact.json`
- `discovery.log`
- `replay-success.log`
- `replay-not-found.log`
- `replay-failure.log`
- screenshots of discovery, successful replay, failure, and escalation

The repository intentionally ignores generated logs/intervention records until you explicitly force-add the sanitized evidence you want to submit.
